What this teaches

This ties directly to Lesson 10's shared-console and jump-host content: a matrix like this is exactly what a least-privilege review produces before anyone touches a physical console. The key teaching point is the Shore Vendor row — the model policy assigns None across all five systems by default. That is not an oversight; it reflects Lesson 10's core recommendation that vendor access should be granted per-session through a jump-host pattern, logged and time-bounded, rather than standing as a permanent entry in the access matrix. A vendor row with any standing access at all is, by itself, worth flagging in a real review — regardless of what that access level is.
