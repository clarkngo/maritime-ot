Before You Use This Tool

⚠️ Before You Use This Tool

This tool assembles a text prompt — it does not call any AI service and does not generate content itself. Whatever an AI assistant returns from the prompt below is a first draft only and requires subject-matter review before it reaches learners, per this course's Safeguards & Responsible Use policy.

Do not enter real vendor names, vessel names, port operator names, or any other identifying operational data into the fields below. Keep every field generic and fictional — the generated prompt is designed to produce illustrative, non-attributable teaching material only.
